A standalone, GitHub-compatible git forge in one Node 22 process: git smart HTTP (upload-pack v2, receive-pack v0), the REST v3 API, a GraphQL v4 subset and MCP tools, all served from its own in-memory object store with no dependencies, no git binary and no UI.

## Run it

```sh
MAKEFUN_ENV_URL=http://store:8080 node --experimental-strip-types main.ts
```
